## Formats supportés :
### Images :
- **Formats** : JPG, PNG, WebP
- **Taille pour expériences** : 1200x600px (ratio 2:1) - **Augmentée pour plus de netteté**
- **Taille pour profil** : 600x600px (carré) - **Augmentée**
- **Poids** : < 800KB par image (qualité élevée acceptée)

### Vidéos :
- **Format** : MP4 (recommandé), WebM
- **Résolution** : 1280x720px (HD) ou 1920x1080px (Full HD)
- **Durée recommandée** : 30 secondes à 2 minutes
- **Poids** : < 10MB par vidéo (pour un chargement rapide)
- **Codec** : H.264 pour une compatibilité maximale

4. **Test** : L'application charge automatiquement vos fichiers

✅ **Contrôles vidéo** intégrés (play, pause, volume)
